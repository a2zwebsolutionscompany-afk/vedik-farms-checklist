Vedik Farms App

Frontend vs Backend Checklist for Client Review and Product Roadmap

Project Snapshot

The current project shows a polished Android app MVP for a wellness-focused grocery and dairy brand. The frontend experience and product concept are already well developed. However, the system still needs a real backend, database, deployment pipeline, and production security measures before it can be launched for real users.

Frontend Needs Work

Core Frontend Gaps

  • Real API integration instead of mock data
  • User login/signup screens connected to backend
  • Product catalog from server
  • Cart checkout flow with backend validation and order creation
  • Real subscription management
  • Real order tracking status from backend
  • User profile update workflows
  • Admin/product management screens
  • Payment UI integration (Razorpay / Stripe / UPI)
  • Push notifications / order status alerts
  • Better error handling, loading states, empty states
  • Production-ready design for real marketplace flows

Frontend Status

UI / UX Prototype: Ready API Integration: Needed Production Launch: Blocked
  • Basic screens and flows already exist
  • Core product experience is visible
  • Live data layer is still missing
  • Production app quality needs additional QA and polish

Security & Compliance Needs Work

Security Checklist

  • Do not expose API keys in app code
  • Backend must secure all business logic
  • Payment flows must use secure server-side validation
  • User data privacy policy needed
  • Consent flows for data use
  • GDPR / privacy compliance review
  • Anti-abuse controls for AI assistant
  • Role-based admin access
  • Rate limiting / request validation

Assessment: The app is a strong MVP/prototype for a health and dairy commerce brand, but it still requires a production-grade backend, database, payment system, deployment pipeline, and security setup before it can be launched to real customers.
